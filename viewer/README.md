# viewer/ — Viser app
Files:
- object_card.py — Left reference sidebar: up to three distinct source-frame crops from existing object labels, cached-first Muse identity/evidence/uncertainty/capture suggestions and explicit name confirmation (editor undo supported). References tab controls visibility and cache/live requests. Live requests remain permission/budget gated; no automatic calls, online search or new SAM requests. Crops are not pixel masks, and photo analysis cannot diagnose reconstruction holes.
- explain.py — Explain mode: Muse picks parts + narration from close-up photos, SAM 3.1 finds each part, masks are projected onto the object's splats (3D labels) and drawn on a photo diagram. CLI: python -m viewer.explain <run> <id> "<question>".
- sam_isolate.py — SAM 3.1 isolation of one object in 3 views + scan diagnosis (coverage, spill), suggested attachment fix.
- repair.py — Repair tab: object isolation, click-brush with front-depth selection preview, erase/restore, object/contact ownership correction, 30-step undo/redo and explicit visual_repairs.npz save/load with geometry validation. Reassignment requires original pose/size. Visual-only overlays; source labels and physics remain unchanged. Saved repairs load on request. Brush uses scene-unit radius, not pixels; it is a click brush, not continuous freehand painting.
- contact.py — Splits low table-like splats into a stationary capture layer. Contact/reflection layers hide on translation, rotation, resize or removal; scan-derived table fill replaces them. Vertical object bases remain movable. Original scan labels and collision hulls are preserved.
- editor.py — Inspect tab: object picker, names/properties, precise upright placement, size, restore/remove, separation, history, save/load, CSV download, camera presets. All controls are exposed in the Viser web host.
- session.py — Compact 30-step undo/redo and atomic editor_state.json layout persistence; validates geometry identity before load. Scene units are explicit in CSV. Background edits retain their own history; object additions clear layout history.
- app.py — UI: dark theme, title bar, tabs Play / Clean up / Simulate, one-click example commands from object names. Scene (collision hull from <run>/gen/obj_k.obj with a flat base if it stands alone (physics.world.stands_alone), else the scan hull; background crop, object splats, reflection splats, fill splats, hulls, props.json). Compact panel: command box, log, selection, button groups. Click selects. The gizmo moves the object. Release while moving throws it. Physics runs at 60 Hz.
- holefill.py — Flat Gaussians on the object footprint, colour from the table ring, opacity feathered to the edge.
- holefill_ai.py — Muse Image fill: top-down gsplat render, footprints painted magenta (no mask API), edit "clean wood, no reflections"; grey pixels -> table wood colour, sampled into gen/fill_rgb_k.npy (Scene uses it). `sim/run.sh viewer.holefill_ai <run>`. ~$0.01.
- add_object.py — Click to add a missed object: first DENSE surface along the ray (not a floater) -> SAM 3.1 point prompts on up to 6 visible keyframes -> multi-view vote (>= 3 views) over nearby non-table splats, connected piece at the click. Viewer button "add missed object". ~$0.015 per click. Persists in labels.npy.
Run: `python -m viewer.app <run_dir> --port 8000`, then open http://localhost:8000 (default without --port remains 8080).
Tabs (by task): Play (command, examples, selected-object actions, scene buttons, settings folder) / Object (folders: Details & placement, Identify with AI, Fix the scan) / Scene (background clean-up) / Robots. Command feedback = toast at the bottom (4 s), not a panel log. Arrange starts with physics paused; Experiment runs physics. Action commands resume physics. Throw-on-release is optional and off by default. Undo/load pause physics. Saved layouts load on request, not automatically.
Use --load-layout to explicitly restore editor_state.json at startup (physics stays paused). Object state is preserved; undo history is in memory for the current session only.
Planner: local = offline rules; cached = Muse cache replay only; meta appears only when LIVESPLAT_ALLOW_META=1 for an explicitly approved round. Add-missed-object is disabled otherwise. Never enable API access without the user's permission.
Manual dimension calibration is medium priority (docs/EDITOR_PLAN.md); the inspector and CSV currently report uncalibrated scene units. Saved editor layouts are not yet consumed by sim.export.
Clean-up: folder "clean up background" (tabletop mode): Shift + drag a box erases background splats (projection from the client camera), "protect table" (whole table column: glossy tops are faint + reflection splats below the surface), auto clean (radius; min opacity default 0), undo. Saved to <run>/bg_removed.npy (raw indices); used by Scene and sim.export.
Notes: All browser clients share one panel. Do not use the disable_sliders or depth_test options of the gizmo (NaN lines).
